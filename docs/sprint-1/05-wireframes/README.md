# Wireframes de Sprint 1

Tres propuestas de interfaz vectoriales, no un frontend ejecutable:

1. [Login](01-login.svg): RF-01, HU-01; RUT/contraseña y mensajes de error.
2. [Catálogo](02-catalogo-equipos.svg): RF-02 y RF-01, HU-02; consulta, edición, baja y cierre de sesión.
3. [Formulario](03-formulario-equipo.svg): RF-02, HU-02; identificación, ubicación, criticidad y estado.

Fuente: informe §3.1 p.4. El estado mostrado de catálogo corresponde a SUPERVISOR; los otros roles tendrán consultas y logout, sin acciones de escritura. El backend valida de todos modos los permisos. El diálogo de baja expresa la consecuencia para el usuario; la fila se conserva en SQLite. Pendiente revisión visual y aceptación del PO.
